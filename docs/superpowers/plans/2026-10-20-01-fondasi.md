# Fondasi — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Membangu aplikasi Next.js yang sudah bisa login (Google + email/PIN), mengelola master data (paket, add-on, outlet, bank, pengguna), punya shell 5-tab di HP, dan bisa di-install sebagai PWA.

**Architecture:** Satu aplikasi Next.js 16 App Router — frontend dan API dalam satu project dan satu origin (tanpa CORS, cookie same-origin). Halaman dirender sebagai *static shell* + client component; otorisasi ditegakkan di **Route Handlers** (`src/app/api/**`), bukan di render halaman. Database PostgreSQL Supabase diakses via Drizzle + Transaction Pooler. Semua logika bisnis di service layer (`src/lib/services/`) yang menerima `db` sebagai parameter, sehingga bisa diuji tanpa HTTP dan tanpa database eksternal.

**Tech Stack:** Next.js 16.4.2 · React 19.3.1 · TypeScript 5.9.3 · Tailwind CSS 4.3.3 · Better Auth 1.7.12 (@better-auth/drizzle-adapter 1.7.12) · Drizzle ORM 0.45.4 + drizzle-kit 0.31.11 · pg 8.23.1 · Supabase Postgres (Transaction Pooler) · Zod 4.6.7 · Serwist 9.5.13 (@serwist/next 9.5.13) · TanStack Query 5.104.5 · Zustand 5.0.15 · Vitest 5.0.5 + Testing Library + MSW 3.0.3 + PGlite 0.5.10 · Vercel

**Spec:** `prd.md` (root repo) — especially §4 Lingkup, §5.5 Pengaturan, §7 Model Data, §8 Struktur Menu, §9 Arsitektur, §10 Kontrak API, §11 Non-Fungsional

## Global Constraints

- Bahasa UI dan seluruh pesan error: **Bahasa Indonesia**. Nama variabel/kode: **English**. Format angka: Rupiah tanpa desimal (`Rp 65.000`), tanggal `dd/MM/yyyy`.
- **Harga dalam integer Rupiah** (bukan float, bukan sen). Tidak ada nilai desimal di seluruh tabel transaksi.
- **Tidak ada hardcoding nilai bisnis di kode.** Paket, add-on, pajak, bank, gaji harian, dan rules tudo dibaca dari database lewat Pengaturan.
- Akses database **hanya lewat server** (Route Handler / server component). `SUPABASE_SERVICE_ROLE_KEY` tidak boleh muncul di kode client (`src/**` yang tidak diawali `server-only`).
- Semua tabel bisnis memakai nama **snake_case** di Postgres; nama properti Drizzle memakai **camelCase**.
- Setiap endpoint yang mengubah data sensitif wajib mencatat `audit_logs` (aktor, aksi, sebelum/sesudah).
- Hanya satu sumber kebenaran untuk skema: `src/lib/db/schema.ts`. Migrasi = `drizzle-kit generate` -> folder `drizzle/`.
- Test API **tidak boleh** memerlukan database eksternal. Semua test DB pakai **PGlite** (Postgres in-memory).
- Versi dependency **dipin** (tanpa `^` atau `~`) di `package.json` agar build tidak gagal diam-diam.
- Target perangkat: Android 8+ (utama, printer Bluetooth), iOS Safari 16+ (cadangan).

## Review Focus

Lima kondisi yang paling mungkin menggigit pengguna nyata, yang tidak otomatis tertangkap oleh acceptance criteria modul — masing-masing dipin ke task yang memiliki kodenya:

1. **Paket untuk motor tidak boleh bisa dipilih untuk mobil.** Setiap paket/add-on terikat `vehicle_type`; filter dan validasi harus konsisten, bukan hanya di UI. → Task 7 & 8
2. **Harga paket 0 atau negatif harus ditolak**, dan `price_snapshot` di transaksi lama tidak boleh berubah saat harga master diedit. → Task 7
3. **Akun yang dinonaktifkan (`active = false`) tidak boleh bisa dipakai**, termasuk sesi yang sudah ada sebelum akun dinonaktifkan. → Task 6 & 9
4. **PIN 6 digit + email adalah kombinasi lemah.** Siapa pun yang tahu keduanya bisa login sebagai karyawan itu. Mitigasi yang harus ada: PIN bisa di-reset admin, attempts dicatat, dan `role` default user baru adalah `kasir` (bukan `admin`). → Task 5 & 9
5. **Suara/duplikasi data master**: membuat paket dengan nama sama untuk tipe kendaraan sama harus ditolak ( unik komposit), dan add-on dengan nama sama tidak boleh menggandakan baris saat di-seed dua kali. → Task 7 & 8

```ts
import { ZodError } from "zod";

export class HttpError extends Error {
  constructor(public status: number, public code: string, message: string) {
    super(message);
    this.name = "HttpError";
  }
}

export function jsonError(error: unknown): Response {
  if (error instanceof HttpError) {
    return Response.json({ error: { code: error.code, message: error.message } }, { status: error.status });
  }
  if (error instanceof ZodError) {
    return Response.json({ error: { code: "VALIDATION_ERROR", message: error.issues[0].message } }, { status: 400 });
  }
  console.error(error);
  return Response.json({ error: { code: "INTERNAL_ERROR", message: "Terjadi kesalahan pada server" } }, { status: 500 });
}
```

- [ ] **Step 5: Implementasikan `src/lib/auth/session.ts`**

```ts
import { headers } from "next/headers";
import { getAuth } from "./provider";
import { HttpError } from "@/lib/http";
import type { Role } from "@/lib/types";

export type SessionUser = {
  id: string; name: string; email: string; role: Role;
  outletId: string | null; phone: string; dailyRate: number; active: boolean;
};

export async function getSessionUser(): Promise<SessionUser | null> {
  const session = await getAuth().api.getSession({ headers: await headers() });
  if (!session) return null;
  const u = session.user as Record<string, unknown>;
  if (u.active === false) return null;
  return {
    id: String(u.id), name: String(u.name ?? ""), email: String(u.email ?? ""),
    role: (u.role as Role) ?? "kasir",
    outletId: (u.outletId as string | null) ?? null,
    phone: String(u.phone ?? ""), dailyRate: Number(u.dailyRate ?? 0), active: true,
  };
}

export async function requireUser(roles?: Role[]): Promise<SessionUser> {
  const user = await getSessionUser();
  if (!user) throw new HttpError(401, "UNAUTHENTICATED", "Silakan masuk kembali");
  if (roles && !roles.includes(user.role)) throw new HttpError(403, "FORBIDDEN", "Akses ditolak");
  return user;
}
```

```ts
}
```

- [ ] **Step 1: Implementasikan `src/app/sw.ts`**

```ts
import { defaultCache } from "@serwist/next/worker";
import type { PrecacheEntry, SerwistGlobalConfig } from "serwist";
import { Serwist } from "serwist";

declare global {
  interface WorkerGlobalScope extends SerwistGlobalConfig {
    __SW_MANIFEST: (PrecacheEntry | string)[] | undefined;
  }
}

const serwist = new Serwist({
  precacheEntries: self.__SW_MANIFEST,
  skipWaiting: true,
  clientsClaim: true,
  navigationPreload: true,
  runtimeCaching: defaultCache,
});

serwist.addEventListeners();
```

- [ ] **Step 2: Aktifkan Serwist di `next.config.ts`**

```ts
import type { NextConfig } from "next";
import withSerwistInit from "@serwist/next";

const withSerwist = withSerwistInit({
  swSrc: "src/app/sw.ts",
  swDest: "public/sw.js",
  disable: process.env.NODE_ENV === "development",
  register: false,
});

const nextConfig: NextConfig = { reactStrictMode: true };
export default withSerwist(nextConfig);
```

> `register: false` supaya registrasi service worker dilakukan manual di client (Task 12 Step 6) agar bisa waited sampai halaman Kasir siap.
